# 🎹 TypeTone Piano Studio X

A futuristic browser-based piano studio built using pure HTML, CSS, and JavaScript.

TypeTone transforms your keyboard into a playable multi-octave piano with real-time synthesized audio, chord support, recording, looping, custom sound engines, and an interactive piano UI.

---

# ✨ Features

* 🎹 Fully playable keyboard piano
* 🎵 3 octave key mapping
* 🎼 Chord system using `_`
* 🔊 10 synthesized sound engines
* 🌌 Dream pad synth
* 🔔 FM bell synthesis
* 🎛 Additive organ synthesis
* 🔥 Warm analog-style tone
* 🎸 Bass low-pass synth
* ⚡ Bright electric synth
* ⏺ Record & save melodies
* 🔁 Loop playback
* 🎚 Tempo / sustain / volume controls
* 🌗 Light & dark theme
* 📱 Mobile responsive UI

# 🎼 Chord System

Use `_` between keys to play chords.

Example:

q_e_t

Plays:
C + E + G

Minor chord example:

q_3_t

Plays:
C + Eb + G

---

# 📝 Song Format

* Spaces = pause
* `_` = chord
* `/` = ultra-fast separator
* New line = longer pause

Example melody:

"3_5   4  2    3    3_5   4  2    1"
