Song library

Write a song or upload a text file. Saving it puts the song in the piano menu, where the falling tiles use the same keys.

Add a song

Use the letters A–Z. A lowercase letter is the printed key. A capital, or Caps Lock, plays that same key one octave higher. Spaces pause, _ plays a chord, and a new line holds a little longer. Example: x c v or X_V_N.

Z X C V B N M → B C D E F G A A S D F G H J K L → B C D E F G A B C Q W E R T Y U I O P → the sharps Caps Lock lifts the key you typed by one octave

A text file fills the notation box. Its name becomes the title when the title is empty.
